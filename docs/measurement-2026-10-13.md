# Post-fix measurement: the signal does not survive IDX costs

Measured 2026-10-19 on branch `rescue/signal-correctness`, commit `8e4229c`, after
the signal-correctness rescue (`docs/superpowers/plans/2026-10-13-signal-correctness-rescue.md`).

## Verdict

At a realistic 25 bps of slippage per leg the strategy **loses money out of
sample: −1.13% average return, Sharpe −0.30**, over 1,789 closed trades in one
year. Before slippage it earns +3.88% (Sharpe 0.49). The edge before costs and
the round-trip cost are about the same size, so costs decide the outcome.

The in-sample figures for the same window (+76% at a 98% win rate and a 0.52%
max drawdown) come from evaluating models on rows they were trained on. They are
memorisation and are not evidence of an edge.

## Method

| | |
|---|---|
| Holdout fleet | `python src/train.py --parallel --as-of 2025-06-12`, written to `mlruns/holdout-2025-06-12/` (local, not tracked). 45/45 tickers, trained only on rows dated on or before 2025-06-12 (53,241 rows). |
| Embargo | 2025-06-13 excluded: the target is next-day direction, so the cutoff row's label is the first post-cutoff session. |
| Evaluation window | 2025-06-16 to 2026-06-12, 238 sessions per ticker, 10,710 rows, 45/45 tickers, none skipped. |
| Strategy | Long-only, 25% of cash per entry, confidence threshold 0.50, 1,000,000 IDR starting capital per ticker. |
| Costs | Buy leg 0.15% brokerage. Sell leg 0.15% brokerage plus 0.1% final sales tax. Slippage added per leg at 0, 10 and 25 bps. |
| Production fleet (in-sample contrast) | `mlruns/1/models/`, trained on all rows through 2026-06-12, so it saw the evaluation window. |

Commands:

```powershell
# out-of-sample
.\venv\Scripts\python.exe src/backtest.py --start 2025-06-16 --end 2026-06-12 --slippage-bps 25 --model-root mlruns/holdout-2025-06-12/models
# in-sample contrast
.\venv\Scripts\python.exe src/backtest.py --start 2025-06-16 --end 2026-06-12 --slippage-bps 25
```

## Caveats

- **This is not a controlled in/out comparison.** The cutoff also governs SHAP
  feature selection, so the holdout fleet's 60-column schema shares only 45
  columns with production. The out-of-sample figures stand on their own; the
  size of the gap between the two fleets should not be attributed entirely to
  fit-window leakage.
- **"Beat buy-hold" is not alpha.** Mean buy-and-hold over the window was
  −10.31%. A strategy that is at most 25% invested beats a falling market by
  holding cash.
- **One year, one regime.** A single 238-session window in a mostly falling
  market. No confidence interval is computed.
